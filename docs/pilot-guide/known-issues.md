# Known issues in the pilot build (N-03, draft)

Updated 17 Nov 2026. The full list with impact and effort is in [../gap-log.md](../gap-log.md).

| Issue | What you see | What to do |
| --- | --- | --- |
| The installer is not signed yet | "Windows protected your PC" when installing | **More info** > **Run anyway**, only for an installer from the AIOS team |
| Updates do not install from inside AIOS | **Install update** says it is not in this build | Install the new version over the old one; your data is kept |
| Company server answers are not available | A Company conversation cannot be answered | Keep the conversation Local for the pilot |
| Add resources to my AI | The list is an example; **Link** says it is not in this build | Nothing to do; this page is a preview |
| Voice notes | The skill is shown as not available | Coming in a later build |
| An answer interrupted by a crash | The question and the words written so far are kept, marked as not finished | Choose **Ask again** for a full answer |
| Long conversations | AIOS keeps a summary of older messages; the model sees the most recent ones in full | Start a new conversation for a new topic |
| First start after installing is slow | "Starting AIOS…" for up to two minutes | Wait; Windows checks the new program once |
