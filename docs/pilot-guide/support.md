# Pilot support (N-03, draft)

- **Where to ask:** the shared channel **#aios-pilot** (also linked from Settings > About >
  Pilot support).
- **Response time (to confirm):** the next working day.
- **What to include:** what you did, what you expected and what happened, the AIOS version
  (Settings > About), and a screenshot if it helps. Do not paste confidential content.
- **Diagnostic file:** only when support asks. Settings > Troubleshooting > Create a diagnostic
  file. It holds the log files only: no messages, documents, databases or keys.
- **Lost recovery key:** AIOS cannot recover it. While the app still opens, create a new key in
  Settings and back up again.
- **Security concern:** tell the technical reviewer directly (contact in the repository README,
  to be filled in under A-02).
