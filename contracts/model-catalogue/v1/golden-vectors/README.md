# Golden vectors: model-catalogue v1

Empty on purpose. Vectors are generated and added by the freezing ticket **I-01** (freeze: week 4),
together with the `FROZEN` file in `../`. Do not add hand-written vectors before then.

Once frozen, the vectors here run in CI for every implementation of this contract; a change to
an existing vector is a semantic change and needs a new contract version and an ADR.
